# Privacy Policy

Gunita is a client for servers configured by the user. It sends requests to those servers to authenticate, browse media, read metadata, stream or download content, and synchronize progress. The server address and credentials are supplied by the user.

Gunita does not ship or host media content. This repository does not include a third-party analytics or advertising service in the application code at this foundation stage. Network behavior may change as features are added and should be reviewed against the dependency tree for each release.

This policy may be updated when Gunita gains additional integrations or network features.
